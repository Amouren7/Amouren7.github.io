## 项目简介

「终南逸士」是我建立的**八字命理 + 紫微斗数推演体系**。不是把传统术数原样搬来，而是**系统化、可复用、能讲清楚**——让它既是内容创作（博客命理栏目），也是面向用户的推演服务。

## 体系结构

```
命理体系
├─ 八字（四柱）  年柱 · 月柱 · 日柱 · 时柱
│   ├─ 五行分析  日主强弱 · 用神忌神
│   ├─ 十神 / 用神忌神
│   └─ 大运流年  十年一运 · 逐运推演
└─ 紫微斗数
    └─ 十二宫位排盘 + 四化飞星
```

## 核心能力

1. **四柱排盘**：生辰 → 干支四柱 → 五行占比 → 用神忌神
2. **大运流年**：逐运推演 + 流月流年（如入职、搬迁等关键时点的判断）
3. **内容化输出**：把推演转成「谁都能读懂的」命理文章（见博客「玄学命理」栏目）
4. **服务化**：面向用户的推演咨询流程

## 成果与数据

- 体系覆盖 **2 门**术数，全部**人工推演**（非套模板）
- 以完整样本跑通全流程，方法论可复现
- 输出多篇命理推演文章，形成差异化内容栏目

## 复盘与收获

做命理体系最大的收获，是把一门「玄学」变成了**可解释的方法论**。这和技术项目其实是同一件事：**把隐性知识系统化，让结果可复现、可沟通**。

这正是我「白天写代码，晚上排命盘」这句话的由来——技术讲逻辑，命理讲规律，殊途同归。
